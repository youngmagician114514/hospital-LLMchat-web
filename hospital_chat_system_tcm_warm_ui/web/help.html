快速开始

从一份病历开始，完成录入、生成建议与后续问答。

完成一次诊疗记录

  1. 录入病历。在诊疗工作台选择初诊或复诊，填写性别、年龄和本次病历。已有门诊记录时，可直接使用“导入病历”。
  2. 生成建议。填写主诉或现病史后，点击右下角“生成建议”。右侧会逐步显示生成内容。
  3. 查看结果。生成完成后，按西医诊断、主证、兼证、方药与理由查看，也可以复制整份结果或其中一项。
  4. 继续问诊。切换右侧“问诊助手”，围绕本次病历补充提问。修改病历后，再次点击“生成建议”。

用示例熟悉流程

点击工作台顶部“示例病例”，可在导入窗口查看已有示例。点击“识别填充”，内容会按字段填入病历，再点击“生成建议”即可查看完整流程。

选择工作页面

页面用途
诊疗工作台录入病历、查看诊断建议，并结合病历继续问答。
独立问诊围绕单独的问题开展连续对话。

病历录入

工作台左侧按本次病历、复诊记录、图片资料分组。

本次病历

先选择就诊类型并填写性别、年龄，再录入以下内容。主诉和现病史至少填写一项，即可生成建议。

字段填写内容
主诉主要症状、发生部位与持续时间。
现病史起病经过、诱因、加重或缓解因素及伴随症状。
查体活动度、压痛及神经系统体征等检查记录。
影像学/检验MRI、CT、X 线或检验报告的文字结论。
舌脉舌质、舌苔和脉象。
既往史与过敏史既往疾病、用药、家族史和过敏史。

内容较长时，点击字段右侧“展开”，在大窗口中编辑，保存后回到原字段。

复诊记录

选择“复诊”后，可以打开“复诊记录”，填写初诊时间、初诊诊断、初诊方药与剂量，以及服药后变化。切换标签会保留已填写的内容。

图片资料

在“图片资料”中按舌象、检查影像分别添加图片，可查看文件和缩略图。需要分析的检查结论填写在“影像学/检验”中。

草稿与新病历

填写内容会自动保存在当前浏览器，左下角显示保存状态。再次打开同一地址时，会恢复病历文字。

开始下一份病历时，点击顶部“新建病历”。表单与结果会清空，问诊助手也会开始新的会话。

导入与示例病例

将已有记录整理为表单，减少逐项录入。

导入已有病历

  1. 点击工作台顶部“导入病历”。
  2. 将门诊记录或整理好的文字粘贴到“病例”输入框。
  3. 点击“识别填充”。识别出的内容会逐项显示，完成后填入表单。
  4. 根据记录补充或修改字段，再点击“生成建议”。

每次识别填充会开始一份新的病历记录。若要补充当前病历，可以直接编辑相应字段。

载入示例

顶部“示例病例”会打开带有示例文本的导入窗口。在导入窗口内，也可以点击“载入示例”。

示例先显示在输入框中；点击“识别填充”后，才会填入工作台。“清空文本”只清除导入框中的文字。

文字怎样组织

按“主诉、现病史、查体、影像学/检验、舌脉、既往史”分段，便于对应到字段。没有记录的项目可以留空。

主诉：……
现病史：……
查体：……
影像学/检验：……
舌脉：……
既往史与过敏史：……

诊断建议

在右侧查看本次病历对应的结果。

生成与查看

点击“生成建议”，或按 Ctrl + Enter。工作台会切换到右侧“诊断建议”，生成内容逐步显示，完成后整理为各项结果。

结果项内容
西医诊断本次病历的诊断建议。
主证、兼证对应的中医证候。
方药方药建议。
理由诊断与辨证所依据的病历信息。

复制结果

“复制结果”可复制完整内容；各结果项旁的复制按钮用于复制单项。生成完成后，复制按钮才会启用。

修改后重新生成

修改病历后，现有结果会标记为“需重新生成”，复制按钮随之停用。再次点击“生成建议”，即可更新结果。

生成过程中，病历编辑和思考强度切换暂时停用，结束后恢复。

问诊与思考

根据本次病历追问，或开启独立对话。

问诊助手

在工作台右侧切换到“问诊助手”，输入问题后发送。问答会结合当前病历，可以继续补充症状、舌脉信息或复诊变化。

输入框中的快捷问题会先填入文字，点击发送后才提交。切换“诊断建议”和“问诊助手”会保留输入草稿。

独立问诊

打开独立问诊，输入问题即可开始对话。可以连续提问；点击右上角“新会话”清空当前对话并重新开始。

按 Enter 发送，按 Shift + Enter 换行。回复会逐步显示。

思考强度

页面顶部提供四个档位：关闭、中、高、超高。关闭时直接回复；开启后，模型会先思考再输出，较高档位可能需要更长时间。

选择会保存在当前浏览器，工作台与独立问诊共用。导入病历、生成建议和问答都会使用当前档位。

有思考内容时，正文上方会出现“思考过程”。点击可展开查看正在生成的内容，再次点击即可收起。诊断建议与病历识别也支持这一操作。

常见问题与快捷键

为什么还没有显示回复

开启思考后，模型会先思考，再逐步输出正文。有思考内容时，可展开“思考过程”查看。若页面出现请求失败提示，可在请求结束后重试。

页面显示“服务未连接”

确认本机或内网服务已经启动，再刷新页面。如果其他页面也无法访问，请联系维护人员检查服务状态。

为什么无法复制结果

结果尚未生成、正在生成，或病历修改后还未重新生成时，复制按钮会停用。完成本次生成后即可复制。

草稿保存在哪里

病历文字保存在当前浏览器中。更换浏览器、访问地址或清除浏览器数据后，需要重新录入。图片需在打开页面后重新选择。

图片如何使用

图片资料用于页面预览。将检查报告的文字结论填入“影像学/检验”，即可随病历一同分析。
